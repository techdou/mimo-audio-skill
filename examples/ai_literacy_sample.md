# AI 通识课：大模型入门

## 一、课程导入

今天我们先不急着学习复杂的技术细节，而是从一个问题开始：为什么现在大家都在讨论大模型？

大模型的核心价值，并不是简单地替人写几句话，而是能够基于上下文理解任务、生成内容，并在一定程度上帮助我们完成分析、写作、编程和知识整理。

## 二、什么是 Token

Token 是模型处理文本时使用的基本单位。它不完全等同于一个汉字，也不完全等同于一个单词。

对初学者来说，可以把 Token 理解为模型阅读和生成内容时拆出来的小片段。输入越长，消耗的 Token 越多；输出越长，也会消耗更多 Token。

## 三、什么是 Prompt

Prompt 可以理解为你给模型下达的任务说明。一个好的 Prompt 通常包含四类信息：角色、任务、背景和输出格式。

例如，如果你只说“帮我写一篇文章”，模型很难知道你想要什么风格、写给谁看、长度是多少。更好的写法是：你是一名课程讲师，请面向零基础学生，用通俗语言解释什么是人工智能，要求分为三个部分，每部分不超过三百字。

## 四、课堂小结

今天我们理解了三个核心概念：大模型、Token 和 Prompt。接下来学习 AI 工具时，不要只关注按钮怎么点，更要关注自己如何描述任务，如何提供上下文，以及如何判断模型输出是否可靠。
